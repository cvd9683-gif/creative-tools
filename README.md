# Creative Tools

Midterm presentation · Cathy Doss · ITP

**Zero to One:** getting started is the hardest part of making anything, and most creative
tools only help after it. My project is sketch to prototype: draw app screens on paper, take one
photo, click through it, then export your own lines as SVG to Figma or Illustrator.

## Presenting

Open `index.html` in Chrome (or the GitHub Pages link once it's turned on).

| Key | Action |
| --- | --- |
| → · Space · click | next (questions on the last slide appear one at a time) |
| ← | back |
| F | full screen |
| N | speaker notes |

The animations run in the page itself, so they play when you present. The fonts load from
Google Fonts; without an internet connection the slides fall back to standard fonts.
